## description: Analyze an image and generate a comprehensive visual style reference document

## Task

Analyze the provided image and create a detailed **Visual Style Reference** document.

### Input

$ARGUMENTS

### Output Structure

Generate a markdown document with the following sections:

**1. Core Aesthetic**

- Style name (bold, descriptive)
- One-sentence design philosophy
- Key influences or hybrid styles identified

**2. Color Palette**

- List each color with:
  - Color name
  - Hex code
  - Usage context
- Note total color count

**3. Typography System**

- Headline style (weight, family type, scale)
- Body/secondary text treatment
- Hierarchy structure
- Special considerations (bilingual, monospace, etc.)

**4. Key Design Elements**
Break down distinctive visual techniques:

- Textures and treatments
- Graphic elements (lines, shapes, annotations)
- Layout structure and grid system
- Unique stylistic choices

**5. Visual Concept**

- Summarize the design's conceptual bridge
- Explain the relationship between elements
- Suggest ideal use cases

### Guidelines

- Be specific with technical details (hex codes, font classifications)
- Use bullet points for scanability
- Include visual hierarchy in your formatting
- Note contrasts and tensions in the design
- Identify what makes the design distinctive
